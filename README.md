# 见仙 BeyondSight

《见仙》是一部面向 Steam 的原创修仙互动影视游戏。我们从首部游戏的一页故事梗概开始。眼下只做一个选择：哪件事值得让玩家陪男主、女主和兄弟走完整部？

**本轮入口**　[读首部故事候选](当前剧本.md) · [看已采用的创作要求](故事手册.md) · [接着上次的决定写](修改清单.md)

## 我们把故事写到什么程度

| 范围 | 目标 | 什么时候算够用 |
| --- | --- | --- |
| 整个系列 | 留下核心矛盾、主角远期成长和灵瞳真相的工作假设 | 准备埋具体伏笔时，说得出它可能通向哪个答案 |
| 首部游戏 | 写成一个有结局、能独立成立的故事 | 能复述男主为什么非做这件事不可，女主和兄弟各自怎样改变局面，最后谁得到或失去了什么 |
| Demo | 截取一段有起因、有回报、能实际试玩的戏 | 玩家能说出自己看见了什么、做了什么选择，以及后来哪件事因此发生了变化 |

## 从梗概到试玩

| 轮次 | 一起做的事 | 留下的成果 |
| --- | --- | --- |
| 1 · 故事方向 | 比较两个短方向，选出最想追下去的一案 | 一页含结局的首部梗概，存入故事手册 |
| 2 · 人物与规则 | 沿梗概检查每个人图什么，哪条规则真的挡住了他 | 女主、兄弟、对手的行动线，以及首部用得上的规则 |
| 3 · 关键戏 | 试写一次灵瞳带来的收益、一段让人愿意多看一眼的相处、一个玩家想插手的时刻；可以是同一场 | 少量完整分场，必要时做一个高难镜头的小样 |
| 4 · 首部与 Demo | 理顺首部的因果，圈出能在 Demo 里兑现的事件 | 首部事件表，Demo 场景卡、选择与后果 |
| 5 · 试玩与样片 | 用占位画面点通选择，再看一小段表演或灵瞳样片 | 可点击文本、样片与具体试玩反馈 |
| 6 · 修订与制作 | 先修故事和人物，再修选择与对白，最后确认要拍哪些镜头 | 可制作的分场、对应素材和复用清单 |

这些轮次按故事进展推进。比如写不出两个人愿意独处的一场戏，就回头检查他们各自想得到什么；玩家看不懂灵瞳提供的线索，就先改表现，再决定要补哪些台词。
