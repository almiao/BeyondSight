# 互动影游叙事结构参考

**用途：**为《见仙》的 Steam 互动影视形式提供参考，不是项目设定。

| 案例 | 已公开的互动形式 | 《见仙》可借鉴 |
| --- | --- | --- |
| [《完蛋！我被美女包围了！》](https://store.steampowered.com/app/2322560/) | 多位恋爱对象、关系分支与不同结局 | 早期让玩家对不同人物产生偏好，安排可回玩的亲密片段 |
| [《隐形守护者》](https://store.steampowered.com/app/998940/) | 章节推进、立场选择、不同主要结局 | 主线的事件因果与少数关键命运分歧 |
| [《飞越13号房》](https://store.steampowered.com/app/2095300/) | 剧情选择、探索、推理与多结局 | 让交互源于实际任务而非无意义对话 |
| [Late Shift](https://store.steampowered.com/app/584980/) | 连续电影中多次抉择与多个结局 | 先保证电影故事完整，再设计合理的临场选择 |
| [The Centennial Case](https://store.steampowered.com/app/1612780/) | 观看事件、推理与验证 | 后期可通过证据逐渐揭露古仙历史 |

## 当前采用的制作思路

一条完整共通主线，加少量与人物、训练或行动相关的分支；通过可见的后果和角色回应兑现选择，重大分线留到能产生真正不同结果时再做。**分支数量不等于独立长篇数量。**

前期集中少量主要人物、场景和可重用镜头。第一部以陆寻的外门晋升为完整结局，不必提前揭晓古仙之谜。实际时长、视频生成稳定性与重玩价值均需原型验证。
