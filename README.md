# 见仙 BeyondSight

面向 Steam 的原创修仙互动影视游戏，以 AI 生成影视画面、人物关系和修仙成长为主要体验。

**当前选定方向：仙躯之目。** 故事所在天地由仙人遗留的道体演化或承载，主角的眼睛源自这位仙人生前检查自身修炼的内观能力。具体机制仍在完善。

## 项目入口

| 文件 | 用途 |
| --- | --- |
| [故事手册](故事手册.md) | 当前有效的创作要求、已选方向与待定边界 |
| [修改清单](修改清单.md) | 当前要解决的问题、讨论顺序和本轮交接 |

## 接下来做什么

先细化仙躯之目的基础能力、第一次实际收益与内生限制，再讨论能力的阶段性变化、外观和名称。先让一场具体的戏说明主角看到了什么、做了什么、得到了什么。

仙人的身份、主角获得眼睛的具体事件、首部主事件和最终结局尚未确定。

## 资产维护

- 已采用内容更新故事手册；工作假设和未解决的问题明确标注，不把提过的方案自动当成正式设定。
- 每轮更新修改清单，说明确定了什么、下一步做什么。文件版本交给 Git 管理，不重复堆积“最终版”。
- 有实际剧本、人物卡和制作素材后，再增加对应文件。图片、视频和声音登记用途、选用版本、生成参数或提示词及存放位置。
- 当前目录保留有效工作材料；已清理的旧文件仍可通过 Git 历史追溯。
