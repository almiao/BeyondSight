# 见仙 BeyondSight

面向 Steam 的原创修仙互动影视游戏，画面全 AI，采用清楚的故事选择与分支路线，重视人物关系和修仙成长。

**修炼体系四项已定稿：五行、灵根与亲和、可兼修的修行身份、炼气至化神的结构质变。** 完整定义见[修炼体系](修炼体系.md)。灵目观察实际运行的定位暂定保留；来源、获取、是否进阶、后期解密及与灵潮的关系继续讨论。“仙躯之目”是此前选过的来源方向，其内观解释及现有四案尚未解决本轮提出的问题，不作为已经完成的设定。

## 接下来做什么

四项修炼规则已经确认，不再作为平行候选反复比较。当前重点是灵目：来源为何存在、为何能够解析、怎样落到主角身上、是否需要进阶、后期如何逐层解密，以及灵潮在其中承担什么实际作用。创作者认为“内观之眼”不够丰满、现有四案均不足；后续应给明确推荐及必要理由，不把大量未收敛的推论交还创作者。

上一轮“灵目不另设等级”的建议未确认；本轮不默认采用，也不自动采用新的等级方案。人物特色、合术与余势等战斗机制仍待讨论。

创作者进一步明确，需要先看到有吸引力的主角自述、完整故事脉络、男女角色各自的发展和交集，才能判断卖点与可制作性。当前候选用“同窗赴试、同住客栈、共同成长后走向不同去处”串联六段故事，并给出关系分支和 AI 镜头评估；具体故事仍未采用。

故事推进时，可直接根据这份完整提案修改不吸引人的人物或事件，再将最有期待的一场戏写成分场与选项。先验证关系表演和短剑战，不要求创作者先从抽象卖点中作选择。尚未制作视频样片或可玩原型。

此前“第一次共同守夜”仍是影视样章候选；具体玩法、守夜事件、人物配置、师承细节和时间目标均未采用。

灵目来源的完整解释、主角获得眼睛的具体事件、首部主事件和最终结局尚未确定。
