# 互动影游叙事结构参考

> **2026-11-26 阅读说明：** 下方保留历史竞品研究，旧“当前采用”及“创作者确认的互动原则”是已被v0.3替代的设计历史，并非现行规则。现行参考重点为Late Shift等的情境与命运选择、真人互动影游的人物魅力、爽剧的钩子/反转/追更、条件结局与可回看。传统RPG、卡牌协作等只作对照，不开发其战斗、养成、技能强化系统。行业短剧用户与Steam付费市场不等价，AI影视质量与交互增益须实际样片验证。见[现行GDD](../游戏总体设计.md)。

**用途：**为《见仙》的 Steam 互动影视形式提供参考，不是项目设定。

| 案例 | 已公开的互动形式 | 《见仙》可借鉴 |
| --- | --- | --- |
| [《完蛋！我被美女包围了！》](https://store.steampowered.com/app/2322560/) | 多位恋爱对象、关系分支与不同结局 | 早期让玩家对不同人物产生偏好，安排可回玩的亲密片段 |
| [《隐形守护者》](https://store.steampowered.com/app/998940/) | 章节推进、立场选择、不同主要结局 | 主线的事件因果与少数关键命运分歧 |
| [《飞越13号房》](https://store.steampowered.com/app/2095300/) | 剧情选择、探索、推理与多结局 | 让交互源于实际任务而非无意义对话 |
| [Late Shift](https://store.steampowered.com/app/584980/) | 连续电影中多次抉择与多个结局 | 先保证电影故事完整，再设计合理的临场选择 |
| [The Centennial Case](https://store.steampowered.com/app/1612780/) | 观看事件、推理与验证 | 后期可通过证据逐渐揭露古仙历史 |

## 补充研究：恋爱、分支汇合与状态回收（2026-11）

以下按**公开商店／开发商官方功能介绍**总结，不把官方标称的故事选项数量误作完全不同的独立视频数量。

| 作品／来源 | 已公开互动功能 | 对第一部《见仙》的可执行借鉴 |
| --- | --- | --- |
| [《完蛋！我被美女包围了！》Steam](https://store.steampowered.com/app/2322560/) | 六位差异鲜明的女性角色，第一人称互动、关系与多结局，官方宣称百余分支／12种结局 | 三女主必须先有独立魅力和关系事件，再逐渐决定同行重心 |
| [Five Dates 开发商](https://www.walesinteractive.com/fivedates) | 五位约会对象、关系状态追踪和影响结尾的后续对话；官方公布10个不同结果 | 关系选择先影响具体相处，再影响最终人物后日谈 |
| [Late Shift 开发商](https://www.walesinteractive.com/lateshift) | 超过180个限时决策点，7种结局，播放中不停顿 | 用少量短促战术选项制造危机压迫，而非多拍完整长电影 |
| [《飞越13号房》Steam](https://store.steampowered.com/app/2095300/) | 伙伴信任、选择、QTE、收集线索和推理、多种主结局 | 用周野信任和青崖谷证物贯穿故事，避免二人变成纯好感数 |
| [《底特律：变人》开发商](https://www.quanticdream.com/en/detroit-become-human/flowcharts) | 多人物大规模分支、人物生死会改后续大段剧情 | 可借鉴后果连锁，但不宜按大型3D制作规模复制 |
| [《美女，请别影响我成仙》Steam](https://store.steampowered.com/app/3545990/) | 真人修仙恋爱、QTE渡劫、蓄力对波与多结局 | 战斗与修仙玩法应有影视化反馈，不要仅让玩家选择对话 |
| [《不问凡尘》Steam](https://store.steampowered.com/app/4209920/) | 3D修仙养成、AI NPC对话、结缘及自由探索 | 借鉴关系与修炼联动，但自由3D开放世界玩法不适合直接挪到 AI 影视游戏 |
| [inkle ink官方文档](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md) | weave/gather 可以把短分支重新汇合，并通过条件和状态继续叙事 | 《见仙》采用共享大事件＋专属女主事件＋战斗短反馈＋后期统一收束 |

**调研边界：**官方介绍是功能定位，不代表已核对完整游戏内的每一分支节点。上述对《见仙》的推荐为自主设计，并非声称这些作品使用完全相同的预算或算法。
