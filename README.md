## 当前工作焦点

**第一部《山门》：**杂役受欺时兄弟护人、当场追回工分 → 三女主初见与小收获 → 后山夜袭救兄弟 → 初次观法练成旧难关、挣钱买到目标药散 → 公开初试获胜 → 正面击败严承、进入外门 → 反过来照顾周野与人物告别。

当前版本强化每段的实际冲突和回报，尤其是「严承夺场→主角赢初试→终试正面击败严承」的直接对抗，以及从买不起药到靠本领挣到药散的资源回报。下一步固定考核与夜袭的因果规则，写一组前后呼应的冲突／胜利场景作可玩验证。**完整分支树、制作规模与后续剧情尚未定稿。**
