# 见仙 BeyondSight

面向 Steam 的原创修仙互动影视游戏，画面全 AI，采用清楚的故事选择与分支路线，重视人物关系和修仙成长。

**修炼基础与灵目渊源已定稿。** 五行、灵根与亲和、可兼修的修行身份、炼气至化神的结构质变见[修炼体系](修炼体系.md)。2026-11-23，创作者确认并补强“道统独占高阶传承—古仙重构道基并培养独立新道主—稀缺资源与顶层格局被打破—部分道主联合围杀（包括受过古仙帮助的新道主）—遗目留存”的渊源与因果关系，完整底稿见[灵目渊源](灵目渊源.md)。

观法、载法、夺法仍按此前暂定的三阶段方向保留；具体获取事件、进阶条件、承载与反噬另见[灵目机制与成长](灵目机制与成长.md)。

## 当前首部开局候选

- **当前优先剧情候选：**[首部线性故事 v0.2《夜袭开目》](首部线性故事_夜袭开目_v0.2.md)。杂役陆寻与周野共同劳作、认识三位年轻女修；外部未知力量袭击后山禁库，主角救人并初次接入灵目。宗门负责调查，陆寻努力修炼、通过外门选拔。袭击者和遗目来历暂留悬念。此前内部盗目设想不再作为本轮主线。

## 接下来做什么

先审核[首部线性故事 v0.2《夜袭开目》](首部线性故事_夜袭开目_v0.2.md)的日常吸引力、夜袭因果、灵目初次接入与外门选拔的高潮，再按人物关系寻找少量关键互动分支。古仙历史继续遵循已定渊源，观法／载法／夺法的学习与突破条件后续验证。三阶段不强制与人物境界一一对应。世界形成、天道是否具有统一人格、灵潮成因与作用，以及人物特色、合术、余势等战斗机制仍待讨论。

万道共主、开道归隐、自渡归隐三种终局方向及前置逻辑已经确认；具体人物、章节与触发条件仍须设计。新路能否在主角退场后继续存在，取决于此前是否让其他人具备独立成长与保护它的能力，不能只由结尾选项决定。

创作者进一步明确，需要先看到有吸引力的主角自述、完整故事脉络、男女角色各自的发展和交集，才能判断卖点与可制作性。当前候选用“同窗赴试、同住客栈、共同成长后走向不同去处”串联六段故事，并给出关系分支和 AI 镜头评估；具体故事仍未采用。

故事推进时，可直接根据这份完整提案修改不吸引人的人物或事件，再将最有期待的一场戏写成分场与选项。先验证关系表演和短剑战，不要求创作者先从抽象卖点中作选择。尚未制作视频样片或可玩原型。

此前“第一次共同守夜”仍是影视样章候选；具体玩法、守夜事件、人物配置、师承细节和时间目标均未采用。

灵目的本源与宏观冲突不再重开为多来源候选；主角获取事件、首部主事件及各终局的具体实现仍待确定。
