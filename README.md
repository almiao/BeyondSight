# 见仙 BeyondSight

面向 Steam 的原创修仙互动影视游戏，以 AI 生成影视画面、人物关系和修仙成长为主要体验。

**当前选定方向：仙躯之目。基础机制暂定为解析实际运行脉络。** 故事所在天地由仙人遗留的道体演化或承载，主角的眼睛源自这位仙人生前检查自身修炼的内观能力。眼睛分辨、追踪灵力的实际运行，主角通过理解、验证和修炼把所见变成成果。

根据最新反馈，开局讨论已从篇章梗概改为具体的人物与任务组织。当前用“白溪学馆”演示普通出身男主、同窗与女主的相识、师承获得眼睛，以及从准备到共同战斗的任务链。下一步评议这套样案中的背景、人物和事件；新增细节均未采用。

仙人的身份、主角获得眼睛的具体事件、首部主事件和最终结局尚未确定。
