## 编写约定

1. **一个剧情单元是一份文档**，包含该单元的完整前因与结果；在文档内部以S编号分场，每场再细拆关键镜头，必要时标分支C与条件。
2. **单元剧本是详细内容的唯一权威版本**；总纲仅保留因果摘要、世界规则引用和分支接口，不在多个文件复制台词。
3. 统一采用：**状态（已定／待审）→ 目的与人物动机 → 时间线/空间关系 → 完整事件与对白 → 交互与汇合 → 状态输出 → 影视制作难点 → 待确认项**。
4. 所有新人物能力、宗门权限、灵目限制必须符合根目录[人物基础设定](../人物基础设定.md)、[宗门组织体系](../宗门组织体系.md)、[修炼体系](../修炼体系.md)、[灵目机制与成长](../灵目机制与成长.md)。
5. 任何剧情修改如果影响人物身份、动机、地点或下一幕，必须同步修改总纲相关两三句摘要，避免旧版设计混入制作。
