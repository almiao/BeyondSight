## 第一部《山门》

杂役生活、苏禾旧识与秦晚《雨中一线火》惊艳出场 → 严承为夺灵材把陆寻、周野置于险境 → 内门核心裴照雪巡狩青崖谷，一剑封山、救出伤者 → 药庐救治、剑会身份揭晓 → 外部夜袭，陆寻救回濒死周野并初开灵目 → 练成旧难关、挣到药散 → 公开初试与终试赢得外门资格 → 严承试图灭口，陆寻生死反击 → 与旧生活作别。
