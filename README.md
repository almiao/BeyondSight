# 见仙 BeyondSight

**Steam 优先、AI 影视为主体的可互动多分支修仙爽剧。** 2026-11-26 主创明确调整产品方向：不是战斗修仙游戏系统，不是经营养成或灵目解谜游戏。

玩家扮演获得古仙灵目的陆寻，在具有强冲突、机缘、红颜与兄弟情义的修仙故事中，决定如何行动、利用机缘、面对敌人并改变自己的命运。影视是主体，不是升级奖励动画；爽点和人物体验优先，选择必须带来可见后果。

## 旧设计迁移

原《山门》P00+14场工作稿保留为历史剧情素材，七峰开山等已确认主事件保留；不强制沿用原分场顺序、全路线晋升外门或A/B技能解锁。**一女主一种战斗支援、单战最多一位、好感绑定技能强化等旧游戏规则已撤销**，真实剧情中的合作、授法与赠物仍可写。灵目不做正确选项提示器；斗法以预编排影视表现。旧稿不得作为工程需求或正式批量视频生产依据。
迁移前版本见[Git历史快照](https://github.com/almiao/BeyondSight/tree/1271403c47fa171c464fdd912dabc690c1fdd7af)，无需重复保存旧GDD。

## 当前阶段

先验证一个完整多分支样片：单周目8–12分钟、全部成片约20分钟、三个主要结局是建议目标；每条路线有具体短中长期后果。先文字稿与占位互动，再少量AI影视试制，比较线性与互动版本。通过后才重构山门或决定首发范围。工程聚焦视频播放、剧情图、状态、存档、回看和结局探索；Codex通用媒体原型可复用，实际本地代码状态尚未核实。Steam是主要产品，线性爽剧为可选衍生发行。
