## 当前宗门布局

重明峰为主峰；**问剑峰**（顾停舟、裴照雪）、**五灵峰**（贺明筠、秦晚）、**朱箓峰**、**天枢峰**、**百草峰**（孟怀真、济生院苏禾）、**铸星峰**、**万兽峰**组成七座专业峰。庶务、戒律、镇山三堂负责公共事务。

建议维持杂役1,500、外门700、内门120（包括秦晚、含核心真传12）、任职80，总计约2,400名在籍修士；**目前10位长老为七峰首座及三堂长老**。

**宗名重明宗及三位首座姓名已由创作者确认；峰名、人数和具体职业资源仍作为持续打磨的工作设定。**

## 正式玩法规则（2026-11-25）

**每位女主一种专属支援技能；单场战斗最多携带一位女主，也可独行；不做女主间组合技。** 亲疏分初识／熟悉／亲近／定情四阶段，对应支援未获／基础／强化／保持强化并开放恋爱结局。等级通过共同事件和真实交往推进，不能凭好感跨场召唤角色。详见[《山门》第八部分](故事/山门/00_总纲.md)。
