# 见仙 BeyondSight

面向 Steam 的原创修仙互动影视游戏，画面全 AI，采用清楚的故事选择与分支路线，重视人物关系和修仙成长。

**修炼体系四项已定稿：五行、灵根与亲和、可兼修的修行身份、炼气至化神的结构质变。** 完整定义见[修炼体系](修炼体系.md)。2026-11-23，创作者先后同意暂存“窃道者留下的眼”来源候选，以及“观法、载法、夺法”三阶段能力方向。暂存不等于全部定稿；古仙与天道的大秘密、灵目留下的原因、主角的终极追求与不同选择下的结局仍是当前讨论重点。

## 接下来做什么

四项修炼规则已经确认，观法／载法／夺法也已获准暂存。创作者最新澄清：要讨论金手指来源背后的大故事、古仙或天道的秘密、主题世界观，以及随后修炼终末的开放结果。下一份提案应把隐藏历史、当前主要冲突与可达结局连成易懂的故事，不继续以禁制、火术等微观例子替代宏观问题。内观和“判断天地能否成立”的来源吸引力不足，万法楼／重建传承的终极目标也被认为格局不够；后续不把这些当作既定主案。

灵目暂按三阶段方向继续设计，不把它强制并入人物境界；具体突破条件、数值与反噬尚未随此次暂存确认。是否存在统一天道、灵潮成因、古仙真实经历及世界终局仍待选择。人物特色、合术与余势等战斗机制继续保留待讨论。

创作者进一步明确，需要先看到有吸引力的主角自述、完整故事脉络、男女角色各自的发展和交集，才能判断卖点与可制作性。当前候选用“同窗赴试、同住客栈、共同成长后走向不同去处”串联六段故事，并给出关系分支和 AI 镜头评估；具体故事仍未采用。

故事推进时，可直接根据这份完整提案修改不吸引人的人物或事件，再将最有期待的一场戏写成分场与选项。先验证关系表演和短剑战，不要求创作者先从抽象卖点中作选择。尚未制作视频样片或可玩原型。

此前“第一次共同守夜”仍是影视样章候选；具体玩法、守夜事件、人物配置、师承细节和时间目标均未采用。

灵目来源的完整解释、主角获得眼睛的具体事件、首部主事件和最终结局尚未确定。
