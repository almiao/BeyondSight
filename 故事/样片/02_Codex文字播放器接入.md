# Codex 接入：一炉两主文字播放器

当前目录的 [一炉两主.story.json](一炉两主.story.json) 是本样片唯一机器可读内容源；[完整剧本](01_一炉两主_完整剧本.md)由同一数据生成供审稿。格式 v1 为内容交换格式，不假定现有运行时已支持。先检查实际播放器和schema，写薄适配层；不要为此重写视频引擎或旧代码。仅文字演出，不生成画面、不调用LLM或TTS。

- scene节点：act为幕编号，title/setting显示幕标题与时空；按beats顺序呈现visual（电影画面描述）及dialogue数组（角色名＋台词），seconds为未来镜头节奏估算，不是强制文字等待时间；文字可手动下一段，支持自动播放（按文字量调整，可关闭），可回看；最后一段结束进入next。
- choice节点：显示prompt与全部choices.text；点击后原子跳转choices.next，不计时、不出现正确答案；记录选择ID。end节点显示title、summary和outcomes的四个时间层结果，允许重玩、回到分支或查看已解锁结局。不可自动跳进另一结局。选择前的画面不显示未来分支标题或结局。
- start为入口，act标题可从acts读取。节点ID稳定，所有next目标存在；不需要属性、战力、资源配置、好感数值、库存、战斗、视频文件。只用节点、幕、段落、选择历史、已解锁结局作为本次本地状态；回看探索与原正式存档隔离。三条路径可分别从头测试。
- 可在播放器已有video节点旁加text-scene适配或离线纯文字渲染；选择界面复用现有组件。视觉描述与台词均须展示，不只显示剧情摘要。正文不删减；暂不调整内容或强制计时。
- 已做静态图遍历：17节点，3条完整路径，2个选择节点，无不可达节点/缺失目标/环。路径：end.public、end.contract、end.open。这是内容静态检查，不是运行时测试。
- 估算各路线影视时长：end.public 7.1分钟；end.contract 7.8分钟；end.open 9分钟；全部独立scene片段合计15.4分钟，不含选择停顿、分镜桥接与返工。需以文字试玩、剪辑为准，暂不锁时长。
- 交付验收：能从共同开场进入三条结局，所有节点完整呈现、无视频依赖；回放时只呈现该路径实际经历；不同结局不混淆；退出后恢复位置（若已有存档组件则复用）。报告实际运行和测试结果，不把静态检查当试玩通过。
